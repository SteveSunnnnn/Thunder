Source Sans 3, upright SemiBold (weight 600), is used for map labels.

Source: https://github.com/google/fonts/tree/main/ofl/sourcesans3
License: SIL Open Font License 1.1; see OFL.txt in this directory.
The static font is instantiated from the included variable font with fontTools.
The runtime MSDF atlas is generated by scripts/assets/cook_fonts.py.
