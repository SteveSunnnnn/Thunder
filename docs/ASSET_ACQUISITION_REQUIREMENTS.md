# 外部资产需求清单（Format / Content / Precision）

> **文档定位**：本清单是 `3D_ASSET_SPECIFICATION_AND_INVENTORY.md`（资产规范）的
> **采购/制作优先级执行单**——规范回答"资产长什么样"，本文回答"先要哪些、
> 精度多少、怎么交付"。全部约定与既有规范一致；唯一新增类别是 P0 地表
> 可平铺材质（旧规范按纯程序化地形编写，未覆盖）。
>
> **管线前提**：引擎侧三件套（glTF 导入器 → 实例化绘制路径 → 摆放绑定）由
> 引擎开发补齐，先用占位盒子资产打通链路——真实资产到位后即插即用，
> 管线与资产解耦。

## 0. 通用交付规范（所有类别适用）

| 项 | 约定 |
|---|---|
| 模型交付格式 | glTF 2.0 Binary (`.glb`)，单文件自包含；可选 Draco/Meshopt 压缩 |
| 轴向 | glTF 标准：**Y 轴向上**、右手系、模型面朝 **+Z** |
| 原点 | **地面接触面的几何中心**（建筑=墙脚中心；树=根干中心；单位=脚底中心） |
| 单位与比例 | **米**，真实世界尺寸（排屋 10–15 m 长 / 5–8 m 高；厂房 30–60 m） |
| 材质通道 | ORM 三合一：**R=AO，G=Roughness（0 光滑–1 粗糙），B=Metallic**；禁止三参数分图 |
| 法线 | 切线空间，可用独立 RG（BC5 语义，Z 由着色器还原）或标准 RGB；**不得烘焙到 albedo** |
| 色彩空间 | albedo 为 sRGB；ORM/法线为 linear |
| PBR 值域验收 | 绝缘体 Metallic=0、金属件=1.0；albedo 最暗处 ≥ 30/255 sRGB（防黑块）、最亮 ≤ 240 |
| LOD 三角面预算 | 遵循规范 §2：LOD0 8k–35k / LOD1 2k–8k / LOD2 300–1.5k / LOD3 2–50 |
| LOD 贴图 | LOD0 2048² / LOD1 1024² / LOD2 512²（图集）/ LOD3 128² 或无贴图 |
| 命名 | 遵循规范：`arch_<文化>_<语义>_<财富档>_01`、`tex_<文化>_<名>_orm`、`mat_<文化>_<名>` |
| 交付物 | 每资产一个 `.glb`（含 LOD0–3 命名后缀 `_lod0..3`）+ 材质 ini（`thunder_material_cooker` 输入）+ 贴图源文件 |
| 落位清单 | 模型随附一行 cooker 清单（`mesh <lod> <key> <file>`），可直接进 `thunder_asset_cooker` |

## 1. P0 —— 地表可平铺 PBR 材质集（最高优先：成本低、覆盖 100% 地面）

> 现状：地形着色器的分层混合框架完整，但**没有任何材质贴图采样器**——83 处
> 程序化颜色常量在近景呈"塑料感"。本项把程序化颜料替换为真实材质。

| # | 材质集 | 用途 | 精度要求 |
|---|---|---|---|
| 1 | 温带草地（含 2 个色相变体可选） | 全球基底 | 1024²，平铺周期 4 m（≈256 px/m） |
| 2 | 落叶林地面（落叶+腐殖土） | 林地 | 1024² / 4 m |
| 3 | 针叶林地面（松针+裸根） | 寒温带 | 1024² / 4 m |
| 4 | 岩石陡坡（层理清晰） | 山地悬崖 | 2048² / 8 m（悬崖可见面积大） |
| 5 | 干旱沙地（含波纹法线） | 沙漠 | 1024² / 6 m |
| 6 | 水田（淹水+田埂法线） | 东亚农业 | 1024² / 4 m |
| 7 | 旱田垄作 | 旱作农业 | 1024² / 4 m |
| 8 | 积雪（新雪，含微闪烁粗糙度） | 冬季覆盖 | 1024² / 4 m |
| 9 | 河床卵石/滩涂 | 水体过渡带 | 1024² / 4 m |

**每套交付**：albedo + ORM + Normal 三张图；**必须无缝可平铺**（四边连续，
法线同样无缝）；Roughness 有真实变化（湿地更光滑等）；不接受纯噪声生成的
"伪材质"——需要真实表面扫描或照片修作。

## 2. P1 —— 首个文化圈最小建筑套件（打通"模拟→点位→模型"链路）

从规范 §3 西欧套件中抽取**最小可验证集**（首个管线闭环只需要 9 个模型；
全量 18 个×多时代等链路验证后再排）：

| 模型键（规范命名） | 内容 | 真实尺寸参考 | LOD0 面数 |
|---|---|---|---|
| `arch_we_res_poor_01` | 工业城排屋（联排 3–5 栋一体） | 12×6 m，高 6 m | ≤ 8k |
| `arch_we_res_mid_01` | 半独立双拼住宅 | 10×8 m，高 8 m | ≤ 8k |
| `arch_we_res_rich_01` | 奥斯曼式府邸 | 15×12 m，高 15 m | ≤ 12k |
| `arch_we_com_bank_01` | 帝国银行大楼（可作城镇中心地标） | 25×20 m，高 25 m | ≤ 15k |
| `arch_we_fac_textile_01` | 纺织厂（锯齿天窗+烟囱） | 40×25 m，高 18 m | ≤ 12k |
| `arch_we_farm_01` | 农庄谷仓+农舍组合 | 20×15 m，高 10 m | ≤ 6k |
| `arch_we_mine_01` | 矿场井架+料场 | 20×20 m，高 15 m | ≤ 6k |
| `arch_we_port_01` | 码头货栈+吊臂 | 25×15 m，高 12 m | ≤ 8k |
| `arch_we_train_station_01`（可选地标） | 火车总站 | 60×30 m，高 30 m | ≤ 20k |

**每模型交付**：LOD0–3 四级 `.glb` + 材质 ini + 贴图（建筑共用材质集优先：
砖/灰泥/石板瓦/玻璃 4 套 `tex_we_*`，1024²，跨模型复用以省显存）。
**硬性要求**：剪影可辨识（近景的判定标准是轮廓，不是贴图细节）；门窗为
几何开洞或高对比 albedo，禁止单张"假立面"贴图糊墙。

## 3. P2 —— 植被低模 + 公告板（ ForestCanopyInstancer 输入）

| # | 内容 | 交付 | 精度 |
|---|---|---|---|
| 1 | 温带橡树簇（规范 `veg_temperate_oak_cluster`） | LOD0 低模（≤1.5k 三角）+ LOD2 簇 + **水平交叉公告板卡**（1024²，含四季 2 变体可选） | 高 8–15 m |
| 2 | 寒温带针叶簇（`veg_boreal_pine_cluster`） | 同上 | 高 10–20 m |
| 3 | 热带/地中海簇各一（可选，第二优先） | 同上 | — |

公告板卡为远景主消耗——**树在 V3/CK3 里大部分时间就是公告板**，此项性价比
极高；近景低模只需在 20 km 内可看即可。

单位在战略地图上长期以 LOD2/3 形式出现，模型精度要求低于建筑；**先交付

## 5. 明确不需要的（防过度采购）

- 4K/8K 贴图（规范 LOD0 上限 2048²，地图视角用不满）；
- 骨骼动画（第一批不需要：单位用 VAT/实例矩阵是后续话题，先静态）；
- 全部 11 个文化圈套件（先做通西欧一个圈，管线验证后按销量/优先级排）；
- 高模雕刻细节（ZBrush 级雕刻烘焙到 2048² 意义有限，地图视角 5 km 以上）。

## 6. 引擎侧对应承诺（随资产到位即插即用）

| 资产到位时 | 引擎侧必须已就绪 |
|---|---|
| P0 地表贴图 | `world_map.frag` 材质采样器 + 三平面/地图空间 UV + 贴图流送（AssetPack Texture 种类已支持） |
| P1 建筑模型 | glTF 导入器 → cooker 链路、实例化绘制路径、建筑记录→点位摆放、LOD 切换 |
| P2 植被 | ForestCanopyInstancer 接线 + 公告板渲染 + 散布规则 |
| P3 单位 | 单位实例渲染（VAT/矩阵环缓冲为二期） |

引擎侧先用占位盒子资产验证全链路——**资产与管线解耦，互不阻塞**。
