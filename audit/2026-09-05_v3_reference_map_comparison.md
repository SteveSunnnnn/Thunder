>    清晰可见）+ 海面有轻微斑驳纹理；另有雕版点刻装饰（西班牙填色内的点行）。

### 8.2 截图实测补充

- **墨色**：普鲁士大字号标签字核 `#331c1f`（叠在 `#8d5661` 上）反解 → 墨 ≈ `#1c1214`

  大国名随国形拉伸铺满。

## §0 结论摘要

1. **最 surprising 的发现：V3 远景海洋是"近白暖灰"，不是蓝色。**
   三张远景截图实测海洋主导色 `#e0e0d8` / `#f8f8f0` / `#d8d8d0`（带极淡蓝调的纸灰白）；
   缩放到中景（地形视角）海洋才变成深蓝（大西洋实测 `#285070`）。
   **我们刚把远景海洋调成饱和航海蓝（`srgb(0.18,0.35,0.52)` 深海端），与 V3 方向相反** ——
   这是当前与原版之间最大的单项视觉偏差。
2. **政治色本身：V3 是中等饱和，不是粉彩。** 法国绿实测 `#68a868`、普鲁士暗红 `#885058`。
   V3 地图"看起来浅"的来源是**近白海洋 + 白色州界 + 轻盈标签**，不是国家色淡。
   我们昨天改的"国色直铺"方向与此**一致**，无需回退。
3. **第二最大偏差：州级内部白边缺失。** V3 政治图的标志性特征之一是国境内细白色州界
   （17 张图中 6 张清晰可见），而 Thunder 的 live 着色器次级边界已删（`loc_stroke = 0.0`，
   `world_map.frag:1547-1548`）。
4. **近景语言偏差：** V3 近景是**手绘感**的田园地形（画笔纹理的田野/草地/沙丘）+ 广告牌树 +
   小方块 3D 建筑群；Thunder 近景是**写实向 PBR**（雪/岩/沙 splat + 太阳高光）且内容空旷
   （无树/田/建筑）。风格跳变仍在，只是比牛皮纸时代小。
5. 已贴近原版的方面（无需动）：真实地理轮廓、等距圆柱投影+水平环绕、
   ID 栅格→调色板→等值面边界机制、国色直铺、嵌入式半透明衬线国名、
   经纬网、远景微地形阴影、海岸水线/近景浪花。

## §2 V3 地图风格拆解（实测）

### 2.1 远景（战略/政治模式）
- **海洋**：近白暖灰（`#e0e0d8`~`#f8f8f0`），上有：极淡经纬网格线、蓝色虚线贸易航线弧、
  雕版风格淡灰装饰（帆船等，`v3_full_09` 左下角）、赤道带刻度的直线（`v3_full_09`）。
- **陆地**：中等饱和国家色直铺（法国 `#68a868`、普鲁士 `#885058`、瑞典绿、西班牙淡黄、
  俄国米白），色块上有**极轻微**地形阴影起伏（波斯/俄境内可见山影）。
- **边界**：两层——国境内**细白州界**（清晰、半透明）+ 国界略深描边；开战/博弈边界
  橙黄描边（wiki 明文记载）。
- **标签**：衬线体，深灰褐、嵌入地图、半透明；国家名+地区名（"Norrland""Castile"）+
  **海洋名**（"ATLANTIC OCEAN" 巨型字距拉开、浅灰）；随区域面积定字号。
- **无画框**：地图满屏铺开，没有 neatline/木框/桌面。

### 2.2 中景（默认地形视角，`v3_full_13`）
- 手绘自然地形：暖绿田野（带田块纹理）、赭石山地（比利牛斯/阿尔卑斯有阴影线感）、
  浅蓝河流线；**州界白线仍然叠加**；海洋转深蓝 `#285070` + 近岸大陆架浅色环。
- 同一套衬线标签继续显示。

### 2.3 近景
- 画家风地形纹理（非写实 PBR）；**广告牌树**成片；**小方块 3D 建筑群**
  （白/青顶小盒子，含港口码头）；道路/铁路+火车；地标小模型（金字塔）；
  海洋近景转浓郁蓝绿（大陆架绿松石→深海），岸边白浪线，3D 帆船。
- **与远景同一套手绘语言，无风格跳变**——细节渐增，观感恒定。

## §5 偏差清单（按视觉影响排序）

1. **远景海洋过深过饱和**（#5）——当前 `:1219-1221` 近岸 `srgb(0.40,0.61,0.76)` →
   深海 `srgb(0.18,0.35,0.52)`，而 V3 远景是近白暖灰。这是我们昨天调整时
   没有参照下的方向误判，当时保留了"海图蓝"预判；实测 V3 是"zoom 越远海越浅"。
2. **州级白边缺失**（#7）——政治图没有内部行政区划线，色块内部是"空"的；
   V3 的白色州网同时提供行政信息与"地图感"。
3. **近景语言：写实 vs 手绘**（#18）+ **内容空旷**（#19）。
4. **去中心化统一灰**（#10）——西非/东南亚截图显示 V3 给分散政治体柔和专属色，
   完全无组织地区才是米白；统一灰会让殖民地博弈区域失去信息量。
5. 次级缺失（装饰/feature 级）：海名标签、贸易虚线、雕版海饰、前线描边、极地画框多余。

## §6 具体调整建议（供拍板后执行）

**A. 海洋改为"随 zoom 变浅"的 V3 模型（最高优先）**
- `world_map.frag` §2：把 `far_ocean` 的两端色改为近白暖灰，并让深度随 `closeFactor` 变化：
  - 远景端：近岸 `srgb(0.83,0.85,0.84)` → 远海 `srgb(0.72,0.76,0.75)`（对照实测
    `#f8f8f0`/`#e0e0d8`/`#d8d8d0`，保留 3-5% 蓝绿倾向即可）；
  - 用 `mix(far_ocean_light, current_nautical, closeFactor)` 让近景维持现有深蓝
    （近景 PBR 海不变，中景自然过渡，对应 V3 `#285070` 的中景观测）。
- 水线墨强度 0.30 → 0.18-0.22（浅海上墨线要更淡）。
- 可选加分项：淡灰雕版小装饰（帆船/波纹）以低频 hash 撒在远海（强度 ≤0.05）。

**B. 恢复州级内部白边（高优先，纯增益）**
- 数据已齐：`province_id_tex` 就在着色器绑定里。仿 `sovereign_border_smooth` 加一条
  `province_border_smooth`（对 province_id 求等值面），画**细白半透明线**
  （`srgb(0.97,0.97,0.95)`，alpha 随 zoom 淡入淡出：远景 0.5 → 近景 0）。
- 国界墨线保持在上层（先画州界后画国界）。这条同时补偿 Phase B 记录的
  "次级边界已删"缺口。
- 省级色块对比：V3 同国州块间有极淡明度差（同色系 ±3-5% 明度抖动）——
  可选按 `province_id` hash 微调明度，让州界之间更有"行政区划感"。

**C. 去中心化上色策略（中优先）**
- 有 owner 记录的分散政治体：从调色板给**低饱和柔色**（V3 实测约 40-60% 饱和度）；
  完全无组织：米白 `srgb(0.96,0.93,0.85)`。
- 落点：`world_map.frag:1455-1458`（当前统一灰）+ 政治记录侧需给分散体分配色号
  （`PoliticalMapState`/世界包侧决策）。

**D. 近景手绘化 + 内容填充（中期，两条线）**
- **语言统一**：PBR splat 调色向手绘靠——降 specular/glint 强度（`:1290` 附近
  `ocean_spec * 0.85` 与地形高光）、压饱和提暗部、终图 grade 里加轻量暖色 tint；
  目标是"画出来的田野"而不是"照片"。
- **内容填充**（依赖既有设施）：
  1. 树木：`ForestCanopyInstancer` 已实现但只活在烟雾测试里——接线到 live 路径，
     按 moisture/纬度播撒广告牌树（V3 密度参照 `v3_full_06` 挪威森林）；
  2. 农田：按省份耕地属性在 PBR splat 里混入田块纹理（V3 田块是其田园感的主要来源）；
  3. 建筑群/铁路：等网格导入器（近景 3D 审计的 ①②③ 三件套）。
- 优先级：树 > 田 > 建筑。

**E. 小项（低优先）**
- 海名标签：`WorldMapLabelKind` 增加 `Sea` 种类 + 世界包补海名脊线数据，
  渲染用浅灰（非墨色）、字号按海域面积放大、字距拉开。
- 极地 neatline（§7 块）可删——V3 无框满屏。
- 贸易虚线、前线橙黄描边：feature 级，等玩法系统落地时一并做。
